ROU CYBER DEFENSE — サイバー攻撃対応ゲームサイト

【起動方法】
index.html / style.css / app.js の3ファイルを同じフォルダに置き、index.htmlをブラウザで開いてください。
ネット接続やサーバーは不要です。

【iPhoneでの利用】
ZIPを「ファイル」アプリで展開してください。iPhoneではHTMLファイルを直接開く方法によってJavaScriptが制限される場合があります。その場合はPCのブラウザで開くか、GitHub Pagesなどの静的サイトホスティングに3ファイルをアップロードしてSafariでアクセスしてください。

【遊び方】
1. 「インシデントを開始」
2. 「アラート」で異常を確認
3. 「ログ検索」で証拠を突合
4. 「対応オペレーション」で封じ込め・報告
5. 「最終報告」で評価を提出し採点

【安全性】
すべて架空の会社・アドレス・ログです。実際のサイバー攻撃、端末隔離、ネットワーク遮断、データ収集、外部通信は行いません。演習の採点は学習用に簡略化したものであり、実務の手順を完全に再現するものではありません。
